# Bubble Bites website (React + Vite)

Screen 1: home page (navbar, hero, both logos, animations).

## Run it

```bash
npm install
npm run dev      # opens at http://localhost:5173
npm run build    # production build in dist/
```

## Where things are

- `src/App.jsx` - Navbar and Hero components
- `src/App.css` - all styles (colours are CSS variables at the top)
- `public/logo-pani-puri.png`, `public/logo-bite-sip.png` - your logos (swap in higher-resolution files if you have them)
- Menu, Our story, Franchise and Contact sections are the next screens; the nav links already point to `#menu`, `#story`, `#franchise`, `#contact`.
